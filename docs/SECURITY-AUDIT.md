## 修复及验证边界

| 风险 | 处理 |
|---|---|
| 回收站不可用或失败时递归永久删除 | 删除永久回退，仅尝试系统回收站；失败报错、保留原文件。测试模拟回收站失败，确认原数据仍在。 |
| 地图 ZIP 越界、设备文件名、解压容量耗尽 | 跨系统路径校验；拒绝 `..`、盘符、Windows 保留名称和链接写入；最多 50,000 条目，单文件 1 GiB，总展开 8 GiB，按实际流量限额；暂存成功后提交，失败清理。 |
| 导入文件夹内链接与扫描耗尽 | 拒绝符号链接及非普通文件，限制搜索条目、复制数量和字节；导入到新目录，避免覆盖现有世界。 |
| 游戏运行时安装、导入、删除干扰实例 | 共享的进程间独占锁覆盖启动生命周期和地图 / 内容修改，锁放在实例目录外；兼容检查旧版锁。手工改文件或其他不遵守锁的程序不受约束。 |
| 下载写任意路径、恶意重定向、无限流 | HTTPS 主机白名单和每跳目标校验；超时、重定向次数和流容量限制；下载到同目录临时文件，校验成功才原子替换。 |
| 模组 / 资源包本地导入和安装路径 | 验证文件名、扩展名、实例路径和链接，实例锁保护；本地复制使用原子替换，依赖模组安装保留暂存提交方式。 |
| 错误拒绝 ZIP 资源包 | 模组保持 JAR，资源包与光影支持 ZIP；不再复用只允许 JAR 的过滤。 |
| 构建依赖或发布产物被替换 | 锁定版本和 SHA-256，每次构建核验；JAR 内依赖再次核验，自动校验清单，标签发布和来源证明；无长期凭据。 |
| 删除失败后继续删其基础版本 | 删除批处理中检查仍然存在的依赖，保留仍被使用的基础版本。 |

## 剩余限制

- 当前仅有本地玩家启动，尚无微软授权与游戏所有权校验；面向公众分发时，维护者应核对适用条款，并按产品定位补上正版登录与所有权检查。
- 没有对所有代码路径做形式验证、完整动态沙箱分析、二进制杀毒认证或独立渗透测试，不能声明“无木马”。源码未发现主动上传账户、浏览器凭据或自启动植入逻辑，但静态检查不能证明不存在全部恶意行为。
- 游戏、模组和加载器安装器在用户权限下执行。下载来源和哈希只证明来源一致性，不能证明内容安全；官方 Forge / NeoForge 安装器自行下载与执行的后续处理器不受 HFML 网络白名单约束。
- 部分上游只提供 SHA-1，保留该格式用于完整性核对。上游或仓库账户被攻破、受信证书/网络/主机被控制、同用户恶意进程竞争路径，都超出这些检查的完整防护能力。
- 路径检查拒绝常规符号链接越界，但没有声称用 Java API 完全消除所有平台 reparse point / junction 差异及检查与写入间的竞争；不要对不可信进程可写的共享目录运行。
- 多目录回收站操作并非事务。部分步骤失败时，已移入回收站的文件需用户按提示恢复；没有静默永久删除。
- OSV 检查只覆盖锁文件中映射的 Maven 组件，不能发现尚未披露的问题、所有本地原生库漏洞或恶意依赖。完整第三方许可和对应源码随发行 ZIP 提供，方便继续审查。
- 仓库权限、分支/标签规则、双重验证、发布环境审批及私密漏洞报告需要所有者在 GitHub 设置。未配置时不会自动生效。
